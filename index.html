This dashboard reads your real usage percentage and reset times directly from Anthropic, authenticated using the OAuth token Claude Code already stores in your macOS Keychain — no separate login or API key needed.

To enable it:

  1. Install the Claude Code CLI
  2. Run claude auth login (or just use Claude Code normally once — that's enough to store the token)
  3. Click "Sync now" above, or wait up to 10 minutes for the next automatic sync

Without this, the dashboard falls back to a local estimate for window boundaries and skips the "Claude-reported" percentage line on each card.
